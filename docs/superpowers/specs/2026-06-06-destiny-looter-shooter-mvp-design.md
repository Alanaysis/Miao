# Destiny-Inspired Looter Shooter — 设计文档

> 横版 2D 像素风刷宝射击游戏，灵感来自命运 2 的核心刷宝循环与职业 Build 系统。

## 0. 核心玩法定义

**游戏类型：** 横版刷宝射击（Side-scrolling Looter Shooter）
**视角：** 2D 高位俯视角（类 Helldivers 1）+ 鼠标自由瞄准（360°）
**美术风格：** 像素风（32×32 角色）
**人数：** 单人或多人联机
**引擎：** Godot 4.x + C#脚本

### 核心循环

```
入局前配置（武器/护甲/子类/星相/Mod）→ 选择地图 →
进入地图(4房间+1Boss) → 清小怪 → 打Boss →
结算（微光+记忆水晶+解码武器）→ 回大厅 →
Meta商店解锁 → 再来一局
```

**战斗节奏：** 混合式 — 小怪阶段割草爽感，Boss 阶段精准射击 + 走位。

## 1. 多人联机系统

- 游戏可单人游玩，此时游戏不联网，所有运算在本地进行
- 也可切换为多人联机模式，此时房主成为主机，其他玩家作为客机与主机进行连接并加入游戏
  - 客机可加入主机的大厅，也可加入主机正在进行中的游戏
  - 主机控制地图生成、房间生成与怪物生成
  - 怪物的血量、行为状态（射击、攻击、移动、释放技能、死亡等）由主机同步给各客机
  - 玩家进行的操作（射击、移动、释放技能等）会发送信号给其他玩家，在其他玩家处进行相应的画面渲染
  - 客机玩家对敌人造成的伤害、对友军进行的治疗，敌人对客机玩家造成的伤害，由客机计算结果，并传递给主机进行汇总
  - 玩家之间互为盟友阵营，对彼此不造成伤害
    - 玩家使用爆炸类武器等伤害时可以对自己本人造成伤害，但依然不伤害盟友
  - 敌人的掉落物由各玩家独立计算，独立渲染，独立拾取
  - 游戏结算奖励、图鉴、解锁物品等均由各玩家独立拥有

## 2. 武器系统

### 2.1 武器框架（全抄命运 2）

| 武器类型 | 射速 | 伤害 | 弹道 | 手感定位 |
|----------|------|------|------|----------|
| **自动步枪 (Auto Rifle)** | 快 | 低 | 直线 | 适合清小怪 |
| **战斗步枪 (Pulse Rifle)** | 中(3连发) | 中 | 3发点射 | 中距离精准 |
| **斥候步枪 (Scout Rifle)** | 慢 | 中高 | 直线 | 远距离精准 |
| **手炮 (Hand Cannon)** | 慢 | 高 | 直线 | 标志性武器，高爆发 |
| **冲锋枪 (SMG)** | 极快 | 极低 | 直线 | 近距离扫射 |
| **霰弹枪 (Shotgun)** | 慢 | 极高 | 扇形散射 | 近距离爆发 |
| **狙击步枪 (Sniper Rifle)** | 极慢 | 极高 | 直线精准 | 远距离单点 |
| **融合步枪 (Fusion Rifle)** | 蓄力 | 高 | 直线连射 | 蓄力后爆发 |
| **火箭筒 (Rocket Launcher)** | 极慢 | 极高 | AOE爆炸 | 清群/打Boss |
| **刀剑 (Sword)** | 连击 | 高 | 近战扇形 | 近战武器 |

### 2.2 稀有度

每种武器框架下设置不同稀有度的武器各 1 把
白(普通) → 绿(精良) → 蓝(稀有) → 紫(史诗) → 金(传说)
- 白：无 Perk
- 绿：1 个 Perk
- 蓝：2 个 Perk
- 紫：2 个 Perk + 基础属性加成
- 金：2 个 Perk + **独有特性** + 累计击杀升级独有特性

### 2.3 Perk 池

每种武器框架有独立的 Perk 池（从命运 2 抄取）。MVP 中所有武器 Perk 池内容相同。

| Perk | 效果 |
|------|------|
| 杀戮弹夹 | 击杀后下一弹夹伤害+30% |
| 暴击大师 | 暴击率+15% |
| 霰弹扩散 | 散射角+20% |
| 穿透弹 | 子弹穿透1个敌人 |
| 击杀回弹 | 击杀回复1发子弹 |
| 急速射击 | 射速+20% |
| 稳定握把 | 后坐力-30% |
| 猎头者 | 对精英/Boss伤害+25% |

### 2.4 武器拾取与携带

- 手持武器槽位为 **1 把武器**
- 进入游戏时装备一把随机白色武器
- 怪物死亡有概率掉落武器，掉落在地上显示图标 + 稀有度颜色光效
- 走到掉落武器旁边按 **互动键** 弹出选择：
  - **【装备】** — 替换手持槽位武器，旧武器丢弃到地上
  - **【灌注Perk】**（相同稀有度的相同种类武器时可用）— 把新武器的 1 个 Perk 转移到当前武器
    - 白武、绿武不显示灌注选项
    - 金武不可灌注独有特性，仅能灌注普通 Perk
    - 灌注后武器消失，有 1 秒视觉特效 + 音效反馈
  - **【取消】** — 将掉落武器丢回地上

### 2.5 掉落规则

- 白绿蓝武器首次获得即永久解锁，加入全局掉落池
- 紫金武器需要通关特定地图解锁
- 不同地图的武器掉落权重有差异
- 击杀敌人 30% 概率掉武器（待定）
- 稀有度概率由当前层数决定
- 金武仅 Boss 10% 概率掉落
- Perk 从池中随机抽取，不重复

### 2.6 记忆水晶

- 通关地图奖励若干紫色或金色记忆水晶（数量和稀有度与地图难度相关）
- 击杀小怪有极低概率掉落记忆水晶
- 结算时可以**单个点击解码**或**一键全部解码**
- 解码后揭示武器，解锁到武器池中
- 无论通关或失败，局内拾取的水晶都会在结算时显示

## 3. 职业与子类系统

### 3.1 三个基础职业

| 职业 | 定位 | 基础属性 | 超能 |
|------|------|----------|------|
| **泰坦** | 近战坦克 | 高光等/高护甲/低移速 | **烈日锤击** — 跳起砸地 AOE + 击退，3秒近战伤害翻倍 |
| **猎人** | 敏捷远程 | 中光等/高移速/高暴击 | **虚空箭雨** — 扇形射出大量箭矢，穿透所有敌人 |
| **术士** | AOE 法师 | 中光等/中移速/技能CD短 | **电弧新星** — 以自身为中心释放电弧，持续5秒自动攻击周围敌人 |

### 3.2 子类系统（每职业 3-4 个元素子类）

每个子类改变技能效果和超能。入局前选择子类。

**猎人子类：**
| 子类 | 元素 | 技能1 | 技能2 | 超能 |
|------|------|-------|-------|------|
| 虚空 | 紫色 | 闪现（短距瞬移+无敌帧） | 标记（敌人受伤害+20%） | 虚空箭雨（穿透箭矢扇形） |
| 电弧 | 蓝色 | 翻滚（快速位移+短暂无敌） | 雷击（连锁闪电伤害） | 电弧风暴（周围持续电弧伤害） |
| 烈日 | 橙色 | 火焰冲刺（冲刺路径留下火焰） | 燃烧弹（投掷造成持续灼烧） | 黄金枪（3发高伤害精准射击） |
| 冰影 | 白色 | 冰封陷阱（减速区域） | 冰甲（临时护盾+反弹） | 冰影风暴（冻结周围敌人） |

**泰坦子类：**
| 子类 | 元素 | 技能1 | 技能2 | 超能 |
|------|------|-------|-------|------|
| 烈日 | 橙色 | 冲锋（撞到敌人眩晕） | 护盾（吸收伤害） | 烈日锤击（AOE砸地） |
| 电弧 | 蓝色 | 雷霆冲锋（高速冲刺+伤害） | 电弧屏障（电弧护盾） | 雷神之怒（地面电弧波） |
| 虚空 | 紫色 | 虚空之拳（近战AOE+减速） | 虚空屏障（吸收+反弹） | 虚空守护者（团队护盾） |

**术士子类：**
| 子类 | 元素 | 技能1 | 技能2 | 超能 |
|------|------|-------|-------|------|
| 电弧 | 蓝色 | 治疗阵（持续回血区域） | 增幅（射速伤害+50%） | 电弧新星（周围持续电弧） |
| 虚空 | 紫色 | 虚空手雷（追踪+爆炸） | 虚空步（短距传送+无敌） | 虚空坍缩（黑洞吸引+伤害） |
| 烈日 | 橙色 | 火焰之触（近战点燃） | 热浪（向前推进火焰波） | 烈日之剑（召唤火焰剑攻击） |

### 3.3 星相（Aspects）— 局外解锁

- 每个子类有 2-3 个星相
- 星相定义子类的核心玩法方向（如"虚空猎人控制流"vs"虚空猎人流血流"）
- 通过 Meta 商店用微光解锁
- 入局前在装备界面配置到子类上
- 星相可以改变技能行为或提供被动效果

### 3.4 碎片（Fragments）— 局内获取

- 每个子类有 4-8 个碎片（全抄命运 2）
- 碎片按子类分类，只有选择了对应子类才能出现
- 碎片在升级时从 3 个随机碎片中选择 1 个（完全替换现有的 5 个升级选项）
- 碎片提供各种效果：
  - 数值加成类（+暴击率/+移速/+护甲等）
  - 技能增强类（技能CD减少/+范围/+持续时间）
  - 触发类（击杀触发XX/受伤触发XX/技能命中触发XX）
- 碎片效果只在当前局内有效，结算后清除

### 3.5 技能资源

- **超能：** 对敌人造成伤害获得极少量充能，击杀敌人获得少量充能（充能条满时按 F 释放）
- **普通技能：** CD 制

## 4. 装备系统

### 4.1 装备槽位

| 槽位 | 类型 | 提供 |
|------|------|------|
| 武器 | 1 个 | 伤害/射速/弹道 + Perk |
| 头盔 | 1 个 | 光等 + Mod 插槽 ×1 |
| 胸甲 | 1 个 | 光等 + Mod 插槽 ×1 |
| 手套 | 1 个 | 光等 + Mod 插槽 ×1 |
| 腿甲 | 1 个 | 光等 + Mod 插槽 ×1 |
| 职业物品 | 1 个 | 光等 + Mod 插槽 ×1 + 职业特有被动 |

### 4.2 护甲属性

每件护甲有：
- **光等** — 贡献到总光等
- **Mod 插槽** — 1 个，可装备 Mod
- **基础属性** — 随机的血量/护甲/移速加成

### 4.3 Mod 系统

**Mod 类型（全抄命运 2）：**
- **武器增幅类** — +射速/+伤害/+弹匣/+装填速度
- **生存类** — +护甲/+回血/+受伤减免/+复活速度
- **技能类** — -技能CD/+超能充能速度/+技能范围
- **元素增幅类** — +火伤/+冰伤/+雷伤/+虚空伤
- **经济类** — +微光获取/+掉率/+经验获取
- **特殊效果类** — 终结技回满技能/击杀回弹/受伤加速等

**Mod 获取方式：**
- **基础 Mod** — Meta 商店用微光解锁，永久拥有，入局前配置
- **高级 Mod** — 局内从记忆水晶或精英/Boss 掉落，拾取后自动装备到对应槽位

### 4.4 光等系统

- 每把武器有光等数值
- 每件护甲有光等数值
- **总光等** = 所有装备光等之平均值
- 光等影响伤害公式：光等越高伤害越高
- 光等模块可以在 Meta 商店用微光购买，用于升级装备光等

## 5. 掉落与结算系统

### 5.1 局内掉落

击杀敌人掉落：
- **武器**（30% 概率，从解锁池中按权重掉落）
- **记忆水晶**（极低概率，稀有度随机）
- **微光**（较高概率，用于 Meta 商店）
- **光球**（经验球，用于升级选择碎片）

### 5.2 结算流程

无论通关或失败，统一进入结算界面：

```
结算界面：
├── 本局统计（击杀数/用时/层数）
├── 获得微光
├── 获得记忆水晶（局内拾取的）
├── [通关奖励] 额外紫/金记忆水晶
├── 解码界面：
│   ├── 单个点击解码（逐个揭示）
│   └── 一键全部解码
├── 解码结果（武器列表）
│   ├── [保留] — 解锁到武器池
│   └── [分解] — 转化为微光
└── [返回大厅] [再来一局]
```

### 5.3 Meta 商店

Meta 商店用微光购买，**不直接加属性**，解锁内容：

| 类别 | 内容 | 示例 |
|------|------|------|
| 子类解锁 | 解锁新的元素子类 | 解锁猎人电弧子类 |
| 星相解锁 | 解锁子类的星相 | 解锁虚空猎人的"渗透"星相 |
| Mod 解锁 | 解锁基础 Mod | 解锁"击杀回血"Mod |
| 光等模块 | 升级装备光等 | +10 光等模块 |
| 武器解锁 | 解锁特定武器 | 解锁"传说自动步枪" |

## 6. 随机地图与敌人系统

### 6.1 地图（5 个起步）

| 地图 | 主题 | 专属武器池 | 难度 |
|------|------|-----------|------|
| 虫巢 | 虫族巢穴 | 虫族系列武器 | ★ |
| 废墟 | 城市废墟 | 废土系列武器 | ★★ |
| 洞穴 | 地下洞穴 | 矿石系列武器 | ★★★ |

每个地图 = 4 个关卡房间 + 1 个 Boss 房。

### 6.2 房间随机生成

- 每个房间从地形模板中随机选取
- 地形模板定义平台位置、掩体、障碍
- 敌人波次内容随机组合

### 6.3 敌人类型

| 敌人 | 行为 | 特点 |
|------|------|------|
| **小虫** | 直线冲锋 | 数量多，清兵爽感 |
| **远程虫** | 保持距离射击 | 需要走位躲避 |
| **快速虫** | 高速绕圈 | 考验反应 |
| **坦克虫** | 缓慢逼近 | 需要集火 |
| **精英虫** | 随机强化词缀 | 加速/分裂/护盾/回血 |

### 6.4 Boss

每个地图有专属 Boss，三阶段战斗。MVP 先做虫后。

## 7. 界面

### 7.0 大厅

该大厅位于宇宙背景中的一艘飞船上。
玩家可在大厅中移动并互动相应设施。
  - 多人游戏时，所有玩家进入主机的大厅，并可互动相应设施查看自己的配置

大厅中有着数个可互动设施，包括：
- 装备配置机器，可互动打开界面调整装备配置
- 地图沙盘，可选择地图并出击
  - 单人游戏时直接启动新游戏
  - 多人游戏时，选择地图后，所有玩家界面出现准备按钮，全部准备后启动游戏
- Meta 商店
- 保险库（图鉴设施）
- 火力战队通讯仪，用于多人联机功能
  - 可选择切换至多人联机主机模式，允许他人加入游戏
  - 可从主机模式切换回单机模式
  - 可加入他人位于主机模式的游戏，无论是在大厅还是在游戏中

### 7.1 入局前装备界面

独立全屏界面，从 大厅 的相应设施处打开：

## 9. 数据管理

所有游戏数据使用 JSON 配置文件管理：

| 文件 | 内容 |
|------|------|
| `weapons.json` | 武器框架定义、Perk 池、稀有度配置 |
