# Destiny-Inspired Looter Shooter MVP — 设计文档

> 横版 2D 像素风刷宝射击游戏，灵感来自命运 2 的核心刷宝循环与职业 Build 系统。

## 1. 核心玩法定义

**游戏类型：** 横版刷宝射击（Side-scrolling Looter Shooter）
**视角：** 2D 高位俯视角（类Helldivers 1） + 横版 + 鼠标自由瞄准（360°）
**美术风格：** 像素风（32×32 角色）
**人数：** 纯单人（考虑对多人联机功能的兼容）
**引擎：** Godot 4.x + C#

### 核心循环

```
选职业 → 进入随机地图(4房间+1Boss) → 清小怪 → 打Boss →
结算掉落 → 回大厅 → 整理装备/升级Meta → 再来一局
```

**战斗节奏：** 混合式 — 小怪阶段割草爽感，Boss 阶段精准射击 + 走位。

## 2. 武器系统

### 2.1 武器框架（3 种）

| 武器类型 | 射速 | 伤害 | 弹道 | 手感定位 |
|----------|------|------|------|----------|
| **自动步枪** | 快 | 低 | 直线 | 适合清小怪 |
| **霰弹枪** | 慢 | 高 | 扇形散射 | 近距离爆发，适合精英/Boss |
| **手炮** | 中 | 中高 | 直线 | 标志性武器，手感好 |

### 2.2 稀有度

每种武器框架下设置不同稀有度的武器各1把
白(普通) → 绿(精良) → 蓝(稀有) → 紫(史诗) → 金(传说)
- 白：无 Perk
- 绿：1 个 Perk
- 蓝：2 个 Perk
- 紫：2 个 Perk + 基础属性加成
- 金：2 个 Perk + 每种武器关联的**独有特性**效果 + 使用金武累计击杀足量怪物升级该独特被动效果

### 2.3 Perk 池（MVP 8 个）

每把武器设置 Perk 池，MVP中令所有武器 Perk 池内容相同
| Perk | 效果 | 适合武器 |
|------|------|----------|
| 杀戮弹夹 | 击杀后下一弹夹伤害+30% | 全部 |
| 暴击大师 | 暴击率+15% | 自动/手炮 |
| 霰弹扩散 | 散射角+20%，覆盖更广 | 霰弹枪 |
| 穿透弹 | 子弹穿透1个敌人 | 自动/手炮 |
| 击杀回弹 | 击杀回复1发子弹 | 全部 |
| 急速射击 | 射速+20% | 自动/手炮 |
| 稳定握把 | 后坐力-30% | 全部 |
| 猎头者 | 对精英/Boss伤害+25% | 全部 |

### 2.4 武器拾取与携带

- 只能携带 **1 把武器**，1 个槽位（考虑增加）
- 掉落武器在地上显示图标 + 稀有度颜色光效
- 走到旁边按 **互动键** 弹出选择：
  - **【装备】** — 替换当前武器，旧武器丢弃
  - （对相同稀有度的相同种类武器）**【灌注Perk】** — 把新武器的**一个** Perk 转移到当前武器
    - 弹出选择，选择 1 个 Perk 替换当前持有武器的 1 个 Perk
    - 白武、绿武不显示灌注选项
    - 金武不可灌注独有特性，仅能灌注普通 Perk
- 吸收后掉落武器消失
- 吸收有 1 秒视觉特效 + 音效反馈（强化感），不影响人物操作

### 2.5 掉落规则

- 击杀敌人 30% 概率掉武器（感觉概率偏高，待定）
- 稀有度概率由当前层数决定：第 1 层白/绿更多，第 3 层蓝/紫更多
- 金武仅 Boss 10% 概率掉落
- Perk 从池中随机抽取，每把掉落武器上的多个perk不重复

## 3. 职业系统

### 3.1 三个基础职业

| 职业 | 定位 | 基础属性 | 超能 |
|------|------|----------|------|
| **泰坦** | 近战坦克 | 高光等/高护甲/低移速 | **烈日锤击** — 跳起砸地 AOE + 击退，3秒近战伤害翻倍 |
| **猎人** | 敏捷远程 | 中光等/高移速/高暴击 | **虚空箭雨** — 扇形射出大量箭矢，穿透所有敌人 |
| **术士** | AOE 法师 | 中光等/中移速/技能CD短 | **电弧新星** — 以自身为中心释放电弧，持续5秒自动攻击周围敌人 |

### 3.2 普通技能（每职业 2 个）

| 职业 | 技能1 | 技能2 |
|------|-------|-------|
| 泰坦 | **冲锋** — 向前冲刺，撞到敌人眩晕（CD 8秒） | **护盾** — 生成护盾吸收伤害，持续3秒（CD 15秒） |
| 猎人 | **闪现** — 短距离瞬移，无敌帧0.3秒（CD 8秒） | **标记** — 标记敌人，受伤害+20%（CD 15秒） |
| 术士 | **治疗阵** — 放置治疗区域持续回血（CD 15秒） | **增幅** — 射速和伤害+50%，短时间（CD 12秒） |

### 3.3 技能资源

- **超能：** 通过击杀敌人充能（充能条满时按 F 释放）
- **普通技能：** CD 制

## 4. 随机地图与敌人系统

### 4.1 地图结构

每局 = 4 个关卡房间 + 1 个 Boss 房：

```
房间1: 小怪层(3波) → 掉落奖励
房间2: 小怪层(4波) → 掉落奖励
房间3: 精英层(2波精英+小怪) → 更好掉落
房间4: 小怪+精英混合(5波) → 掉落奖励
Boss房: Boss战 → 大量掉落 + 金武概率
```

### 4.2 房间随机生成

- 每个房间从 5-8 种地形模板中随机选取
- 地形模板定义平台位置、掩体、障碍
- 敌人波次内容随机组合（类型 + 数量由当前层数决定）

### 4.3 敌人类型（5 种）

| 敌人 | 行为 | 光等 | 特点 |
|------|------|------|------|
| **小虫** | 直线冲锋 | 低 | 数量多，清兵爽感来源 |
| **远程虫** | 保持距离射击 | 低 | 需要走位躲避 |
| **快速虫** | 高速绕圈 | 低 | 闪避难，考验反应 |
| **坦克虫** | 缓慢逼近 | 高 | 需要集火，霰弹枪目标 |
| **精英虫** | 随机拥有1种强化词缀 | 很高 | 词缀：加速/分裂/护盾/回血 |

### 4.4 Boss："虫后"（三阶段）

- **阶段1（100%-60%）：** 召唤小虫 + 地面毒液攻击。走位躲毒，清小虫
- **阶段2（60%-30%）：** 冲锋攻击 + 召唤精英虫。需要闪避 + 优先击杀精英
- **阶段3（30%-0%）：** 狂暴，攻击速度加快，全屏毒液逐渐收缩。DPS 检测

每个阶段切换时有短暂硬直，是输出窗口。

## 5. Meta 进度与收藏图鉴

### 5.1 结算流程（每局结束后）

- 显示本局通关使用的武器
- 显示本局击杀数/用时/层数
- 计算本局获得的微光（货币）

### 5.2 Meta 永久升级

| 升级项 | 效果 | 最大等级 | 费用递增 |
|--------|------|----------|----------|
| 基础光等 | +10 HP/级 | 10级 | 100/200/400... |
| 基础伤害 | +5% 伤害/级 | 10级 | 100/200/400... |
| 移动速度 | +3% 移速/级 | 5级 | 150/300/600... |
| 掉率提升 | +5% 掉率/级 | 5级 | 200/400/800... |
| 初始武器 | 开局自带绿武/蓝武 | 2级 | 500/1500 |

货币：**微光**（Glimmer），通过击杀敌人和完成游戏获得。

### 5.3 收藏图鉴

- 图鉴包含以下分类：武器、Perk、敌人等
- 各武器展示属性、是否使用通关、获取次数等信息
    - 各武器展示可获取的 Perk 池，以及是否携带Perk通关过
    - 金武展示独有特性
- 各 Perk 展示描述
- 每解锁 10 个条目，永久 +2% 全局伤害加成
- 数据持久化到本地文件

## 6. UI 与操作

### 6.1 操作方案

该方案保存到配置文件中，以便后续修改
| 操作 | 按键 |
|------|------|
| 移动 | WASD / 方向键 |
| 瞄准 | 鼠标 |
| 射击 | 鼠标左键 |
| 拾取武器/互动 | E |
| 技能1 | Q |
| 技能2 | R |
| 超能 | F（充能满时可用） |
| 切换武器信息显示 | Tab |

### 6.2 HUD 布局

```
┌─────────────────────────────────────────┐
│ [光等条] [护盾条]         [小地图(可选)] │
│                                         │
│                                         │
│                                         │
│                                         │
│[技能Q][技能R][超能能量]  [武器名+Perk图标]│
└─────────────────────────────────────────┘
```

- 左上：光等条 + 护盾条
- 左下：技能图标 + CD 转圈
- 右下：当前武器名称 + Perk 图标 + 超能充能条
- 准心：鼠标位置十字线

### 6.3 大厅界面

```
┌─────────────────────────────────┐
│         [角色立绘]              │
│   当前武器: [武器名] [Perk]     │
│                                 │
│   [开始新局]  [Meta升级]  [图鉴] │
└─────────────────────────────────┘
```

## 7. MVP Scope

**目标：** 2-3 周内跑通完整核心循环。

| 内容 | 数量 |
|------|------|
| 职业 | 1 个（先做猎人，敏捷远程最适合验证射击手感） |
| 武器类型 | 3 种（自动步枪/霰弹枪/手炮） |
| Perk | 8 个 |
| 地图 | 1 个模板集（5 种房间地形） |
| 敌人 | 5 种 + 精英词缀 |
| Boss | 1 个（虫后，三阶段） |
| Meta 升级 | 5 项 |
| 收藏图鉴 | 基础版 |

**MVP 之后的扩展方向（不在本次范围内）：**
- 猎人/术士职业
- 更多武器类型和 Perk
- 更多 Boss 和地图主题
- 子类系统（元素属性切换）
- 更多精英词缀

## 8. 技术架构

基于现有 `experiment/roguelike` 分支的 C# 代码改造。

### 需要改造的模块

| 现有文件 | 改造内容 |
|----------|----------|
| `Player.cs` (136行) | 加自由瞄准（鼠标角度计算）、技能系统、装备槽 |
| `Enemy.cs` (116行) | 加精英词缀系统、Boss 阶段逻辑 |
| `Weapon.cs` (46行) | 加 Perk 系统、稀有度、随机词条生成 |
| `Bullet.cs` / `Projectile.cs` | 适配新武器弹道（霰弹散射、穿透） |
| `GameManager.cs` (109行) | 改为刷宝循环（房间→Boss→结算） |
| `SpawnManager.cs` (119行) | 改为随机房间 + 波次生成 |
| `LevelUpManager.cs` (138行) | 改为掉落结算 / 装备管理 UI |
| `MetaProgression.cs` (114行) | 扩展 Meta 升级 + 微光货币 |

### 需要新增的模块

| 新文件 | 职责 |
|--------|------|
| `PerkSystem.cs` | Perk 池定义、随机组合、Perk 效果应用 |
| `LootTable.cs` | 掉落表（武器/Perk/微光概率） |
| `EquipmentSlot.cs` | 装备槽位管理、武器替换/吸收逻辑 |
| `CollectionCodex.cs` | 收藏图鉴数据、解锁进度、全局加成 |
| `RoomGenerator.cs` | 随机房间生成（地形模板 + 敌人波次） |
| `BossAI.cs` | Boss 阶段状态机 |

### 数据存储

- `meta_progress.json` — Meta 升级等级、微光余额
- `collection_codex.json` — 已解锁的武器/Perk 记录
- 当前装备状态不持久化（每局重新开始）
