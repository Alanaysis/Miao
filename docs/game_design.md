## 当前实验方向

### Roguelike 类型（实验中）

**分支**：`experiment/roguelike`

**核心玩法假设**：
- 随机生成的关卡和敌人
- 单局游戏时长15-30分钟
- 死亡后重新开始，但保留部分进度
- 通过战斗获取资源，强化角色
- 考虑支持多人联机游玩

**参考游戏**：
- Brotato
- Halls of Torment
- Vampire Survivors

**待验证问题**：
1. 核心战斗循环是否有趣？
2. 随机生成的可玩性如何？
3. 美术风格选择（像素风？简约风？）
4. 单局时长是否合适？

## 设计原则

1. **简洁优先**：核心玩法简单易懂
2. **快速迭代**：小步快跑，快速验证
3. **AI友好**：设计便于AI辅助实现
4. **可测试**：核心系统可独立测试
