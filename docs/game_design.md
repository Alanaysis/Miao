## 当前实验方向

### ARPG 类型（实验中）

**分支**：`experiment/ARPG`

**核心玩法假设**：
- 俯视角半开放式RPG游戏
- 利用不同的主被动技能构造玩法
- 围绕1-2个核心技能设计战斗
- 富有挑战性的BOSS与地图涉及

**参考游戏**：
- 远星物语
- 皓白初晓
- 传说法师

**待验证问题**：
1. 核心战斗循环是否有趣？
2. 可玩性如何？
3. 美术风格选择（像素风？简约风？）
4. 是否具有足够正反馈？

## 设计原则

1. **简洁优先**：核心玩法简单易懂
2. **快速迭代**：小步快跑，快速验证
3. **AI友好**：设计便于AI辅助实现
4. **可测试**：核心系统可独立测试
